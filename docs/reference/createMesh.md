# Reconstruct a Triangular Mesh from a 3D Point Cloud

Reconstructs a triangular surface from a 3D point cloud using linear
binning and Marching Cubes, and returns the result as a `mesh3d` object.

## Usage

``` r
createMesh(
  panel,
  resolNbin = c(4, 4, 2),
  meshCad = NULL,
  zeroBorder = FALSE,
  kFactor = NULL,
  truncFactor = 3.5,
  levelFactor = 0.99,
  coverageTol = 0.99
)
```

## Arguments

- panel:

  A numeric matrix or data frame with three columns containing the X, Y,
  and Z coordinates of the point cloud.

- resolNbin:

  A numeric vector of length three defining the approximate binning
  resolution in the X, Y, and Z directions. Default is `c(4, 4, 2)`.

- meshCad:

  Optional `mesh3d` object used as a reference for the spatial coverage
  of the reconstructed surface. Default is `NULL`.

- zeroBorder:

  Logical. If `TRUE`, adds a zero-valued layer around the X and Z limits
  before surface extraction. Default is `FALSE`.

- kFactor:

  Numeric factor used to determine the tolerance for removing
  low-density nodes. If `NULL`, it is selected automatically. Default is
  `NULL`.

- truncFactor:

  Numeric factor used to truncate high-density node weights. Default is
  `3.5`.

- levelFactor:

  Numeric factor used to define the isosurface extraction level. Default
  is `0.99`.

- coverageTol:

  Numeric value between 0 and 1 defining the minimum spatial coverage
  required relative to the reference bounding box. Default is `0.99`.

## Value

A list containing:

- `mesh`: reconstructed surface as a `mesh3d` object.

- `bin`: processed binning object.

- `contours`: disconnected surfaces generated by Marching Cubes, ordered
  from largest to smallest.

- `params`: parameters used during reconstruction.

## Details

Linear binning is performed with
[`npsp::binning()`](http://rubenfcasal.github.io/npsp/reference/binning.md)
and the grid coordinates are obtained with
[`npsp::coordvalues()`](http://rubenfcasal.github.io/npsp/reference/coordvalues.md).
Low-density nodes are removed and high-density weights are truncated
before extracting the isosurface with
[`misc3d::contour3d()`](https://rdrr.io/pkg/misc3d/man/contour3d.html).

When `zeroBorder = TRUE`, one zero-valued layer is added on both sides
of the X and Z directions to facilitate surface closure.

If several disconnected surfaces are produced, they are ordered by size
and progressively merged until the reconstructed surface reaches
`coverageTol` times the dimensions of the reference bounding box.

## See also

[`npsp::binning()`](http://rubenfcasal.github.io/npsp/reference/binning.md),
[`npsp::coordvalues()`](http://rubenfcasal.github.io/npsp/reference/coordvalues.md),
[`misc3d::contour3d()`](https://rdrr.io/pkg/misc3d/man/contour3d.html),
[`rgl::tmesh3d()`](https://dmurdoch.github.io/rgl/dev/reference/mesh3d.html)

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the theoretical CAD model
data("cad", package = "dimControl")

# Prepare the theoretical panel mesh
meshTeor <- preparePanelMesh(cad)

# Simulate panel points without floor points
panel <- simulatePanelFloorCloud(
  mesh = meshTeor,
  nPanel = 1e7,
  nFloor = 0,
  seed = 1
)

# Reconstruct the mesh from the panel point cloud
result <- createMesh(
  panel = panel,
  resolNbin = c(4, 4, 2),
  zeroBorder = TRUE
)

mesh <- result$mesh

# Display point cloud and reconstructed mesh side by side
rgl::clear3d()
rgl::mfrow3d(1, 2)

rgl::points3d(panel, col = "blue")
rgl::title3d("Panel point cloud", level = 4)

rgl::next3d()
rgl::shade3d(mesh, col = "lightgray")
rgl::title3d("Reconstructed mesh", level = 4)
} # }
```
