# CAD Object of a Steel Panel

A portion of the theoretical CAD model of a steel panel, represented as
a `mesh3d` object.

## Usage

``` r
cad
```

## Format

A `mesh3d` object with the following components:

- vb:

  A 4 x 267 matrix containing vertex coordinates in homogeneous form.

- it:

  A 3 x 343 matrix containing triangle indices.

- normals:

  A 4 x 267 matrix containing vertex normals.

## Source

Theoretical CAD model of a steel panel.
